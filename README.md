## 🚀 Project Overview
**Phone List Project** is a **C++** console-based application designed to manage a phone directory using **OOP** principles and basic **CRUD** operations (Create, Read, Update, Delete).  
It allows users to add, edit, delete, and search phone records while saving data to a local file.

---

## 🌟 Features
- 📝 Add new phone entries.
- ✏️ Edit existing phone entries.
- ❌ Delete phone entries.
- 🔍 Search for specific phone numbers.
- 💾 Save and load data from a file.
- 🎛️ Interactive console interface.
- 🏗️ Demonstrates OOP concepts in C++.

## 💻 How to Run

1. Clone the repository:
```
git clone https://github.com/Ahmed-Ragheb2003/Phone-List-Project.git
```

2. Open the solution Phone Project.sln in Visual Studio.

3. Build the project (Ctrl + Shift + B).

4. Run the application (F5 or Ctrl + F5).

5. Follow the interactive prompts to manage your phone list.
